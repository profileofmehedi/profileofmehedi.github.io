# Mehedi & Sultana Story Project

This project contains three different web-based designs to showcase the "Mehedi & Sultana Story" through a series of photos and captions.

## Project Structure

- `images/`: Contains all the story photos (r11.png to r30.png).
- `design 1/`: An interactive storybook style with a slide-based layout.
- `design 2/`: A modern vertical scrolling timeline with reveal animations.
- `design 3/`: A realistic 3D flip-book experience optimized for both desktop and mobile.

## Features

- **Mobile Friendly**: All designs are responsive and work smoothly on mobile devices.
- **Bengali Support**: Uses the Hind Siliguri font for beautiful Bengali typography.
- **Interactive Animations**: Each design features unique transitions and animations (slides, timeline reveals, and 3D page flips).

## How to View

Simply open the `index.html` file within any of the design folders in your web browser.
