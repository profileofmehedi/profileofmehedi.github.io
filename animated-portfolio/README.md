# Premium Animated & Interactive Portfolio

This folder contains a custom-designed, highly interactive, and responsive portfolio designed for **Mehedi Hasan**, Lead .NET Developer. It is integrated directly within the GitHub Pages repository workspace and is accessible online at `https://profileofmehedi.github.io/animated-portfolio/`.

## 📁 File Structure

```text
animated-portfolio/
├── index.html   # Main structure with semantic HTML5 elements & SEO tags
├── style.css    # Custom CSS variables, responsive styling, and animations
├── script.js    # Interactive features, Canvas particles, cursor tracking, and modals
└── README.md    # Documentation (This file)
```

## ✨ Features & Interactive Elements

1. **Dark Space Aesthetics**: Built with premium tailored HSL color codes (deep blues, purples, electric cyan gradients) optimized for developers.
2. **Interactive Particles Canvas**: Dynamically generated stars/networks bouncing and drawing interactive connection links relative to the user's cursor.
3. **Custom Pointer Cursor**: A secondary magnetic, expanding cursor circle that snaps and shifts scales during anchor transitions.
4. **Typewriter Console**: Simulates a live `.NET Core` server loading log on page entry.
5. **Project Category Filter**: Real-time filtering system for Web Apps and APIs & Services.
6. **Detailed Architectural Modals**: Glassmorphism overlays displaying specific company roles, technical stack, and achievements for enterprise-level projects.
7. **Scroll-Entrance View**: Elements sliding and fading in automatically using light-weight `IntersectionObserver` controllers.
8. **Responsive Layouts**: Fully mobile-first design scaling from ultra-wide desktops down to compact phone screens.

## 🚀 How to Run Locally

You can run this project using any static file server:

### Option A: VS Code Live Server
1. Open this folder in VS Code.
2. Click **Go Live** in the bottom-right status bar.

### Option B: Node http-server
Run the following commands in your shell:
```bash
npm install -g http-server
http-server ./animated-portfolio
```
