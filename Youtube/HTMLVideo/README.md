# 🎬 AI Security Masterclass — 1080p Motion Graphics Video Studio

একটি পূর্ণাঙ্গ, আন্তর্জাতিক ব্রডকাস্ট-গ্রেড **YouTube Video Production Suite**, যা তৈরি করা হয়েছে **HTML5, CSS3, JavaScript, Web Audio API, এবং Three.js 3D** দিয়ে।

এই স্টুডিওটি শীর্ষস্থানীয় টেক ইউটিউব ডকুমেন্টারি ও এক্সপ্লেইনার ভিডিওর আদলে তৈরি (**Vox, Johnny Harris, Bloomberg Originals, Learn with Sumit**)।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ

### 🖥️ ১. নিখুঁত ১৯২০ × ১০৮০ পিক্সেল (16:9 Full HD) ব্রডকাস্ট ফ্রেম
- প্রেজেন্টার স্ক্রিনটি (`index.html`) অভ্যন্তরীণভাবে নিখুঁত **1920 × 1080px** রেজোলিউশনে লক করা।
- **OBS Studio**-তে Browser Source বা Window Capture করার জন্য ১০০% অপ্টিমাইজড (কোনো স্ট্রেচ বা ব্লার নেই)।
- ছোট বা বড় স্ক্রিনে ওপেন করলেও স্বয়ংক্রিয় অটো-ফিট স্কেলিং কাজ করে।

### 🎨 ২. লাইট ব্যাকগ্রাউন্ড ও নো-হিজিবিজি (Zero Clutter) মিনিমালিজম
- চোখ জুড়ানো পার্ল-হোয়াইট (`#f8fafc`) স্টুডিও ব্যাকগ্রাউন্ড ও অ্যাম্বিয়েন্ট শ্যাডো।
- কোনো অপ্রয়োজনীয় ফুটর বা বাটন নেই।
- টপ বারে শুধু মিনিমাল `AI SECURITY`, `REC 1080P`, লাইভ রানিং টাইমকোড (`TC 00:00:00:00`) এবং অডিও ইকুয়ালাইজার বার।

### ✍️ ৩. জেনুইন কালপুরুষ (Kalpurush) ফন্ট
- লোকাল `fonts/kalpurush.ttf` ফন্ট দিয়ে প্রতিটি বাংলা হরফ ক্রিস্টাল ক্লিয়ার রেন্ডার হয়।

### 🎙️ ৪. সুমিত সাহা (Learn with Sumit) স্টাইলের প্রাঞ্জল বাচনভঙ্গি
- ১৫টি অধ্যায়ের সম্পূর্ণ বাংলা স্ক্রিপ্ট সুমিত সাহার পরিচিত ভঙ্গিতে সাজানো (*"আসসালামু আলাইকুম এভরিওয়ান...", "ব্যাপারটা কিন্তু খুব ইন্টারেস্টিং...", "আমরা ডেভেলপাররা যে ভুলটা করি..."*)।
- `voiceover_script.txt` ফাইলে প্রতি অধ্যায়ের দৃশ্য ও সাউন্ড কিউ সহ স্ক্রিপ্ট এবং এক ক্লিকে AI ভয়েসওভার (ElevenLabs / Clipchamp) বানানোর জন্য ক্লিন টেক্সট রয়েছে।

### 📊 ৫. ৩D গ্লাস ইনফোগ্রাফিক্স ও ডেটা ভিজ্যুয়ালাইজেশন
- জেমিনি এআই দিয়ে তৈরি হাই-রেজোলিউশন ৩D গ্লাস আর্কিটেকচারাল ইমেজ:
  - `prompt_injection_hero.jpg` (প্রম্পট ইনজেকশন হ্যাকিং)
  - `data_poisoning_hero.jpg` (ট্রেইনিং ডেটা পয়জনিং)
  - `defense_shield_hero.jpg` (মাল্টি-লেয়ার এআই গার্ডরেইল ডিফেন্স)
- ইন্টারেক্টিভ এসভিজি ডোনাট চার্ট (২০২৬ সালের থ্রেট পরিসংখ্যান)।
- থ্রি.জেএস (Three.js) সিনেমাটিক ৩D ক্রিস্টাল কোর ও ক্যামেরা ডলি মুভমেন্ট।

### 🔊 ৬. প্রসিডিউরাল সাউন্ড ডিজাইন (`js/audio-sfx.js`)
- **Web Audio API** দিয়ে কোনো অডিও ফাইল ছাড়াই রিয়েল-টাইমে স্টুডিও সাউন্ড তৈরি হয় (Whoosh, Sub-drop, Glitch, Chime)।

## 🚀 কীভাবে চালু করবেন?

### অপশন ১: উইন্ডোজ ব্যাচ স্ক্রিপ্ট দিয়ে (সবচেয়ে সহজ)
`start.bat` ফাইলে ডাবল ক্লিক করুন। এটি স্বয়ংক্রিয়ভাবে লোকাল সার্ভার চালু করে ব্রাউজারে হাব ওপেন করে দেবে।

### অপশন ২: ম্যানুয়ালি টার্মিনাল দিয়ে
```bash
node server.js
```
তারপর ব্রাউজারে প্রবেশ করুন:
- **লঞ্চ হাব:** `http://localhost:3000`
- **প্রেজেন্টার ভিউ (1080p):** `http://localhost:3000/index.html`
- **টেলিপম্পটার ভিউ:** `http://localhost:3000/teleprompter.html`

## 🎥 OBS Studio দিয়ে রেকর্ডিং গাইড

1. **Browser Source (সবচেয়ে নিখুঁত):**
   - OBS-এ Add Source `(+)` থেকে **Browser** নির্বাচন করুন।
   - URL: `http://localhost:3000/index.html`
   - Width: `1920`
   - Height: `1080`
   - FPS: `60`
2. **Window Capture:**
   - ব্রাউজারে `index.html` ওপেন করে কীবোর্ডে <kbd>F</kbd> চেপে ফুলস্ক্রিন করুন।
   - OBS-এ **Window Capture** নির্বাচন করুন।

| কি (Key) | অ্যাকশন |
|---|---|
| <kbd>Space</kbd> / <kbd>→</kbd> | পরবর্তী স্লাইড |
| <kbd>←</kbd> | পূর্ববর্তী স্লাইড |
| <kbd>F</kbd> | ফুলস্ক্রিন টগল (1080p Lock) |
| <kbd>M</kbd> | সাউন্ড এফেক্ট মিউট / আনমিউট |
| <kbd>T</kbd> | টেলিপম্পটার উইন্ডো ওপেন |
| <kbd>C</kbd> | (টেলিপম্পটারে) AI ভয়েসওভার স্ক্রিপ্ট কপি |
| <kbd>↑</kbd> / <kbd>↓</kbd> | (টেলিপম্পটারে) স্ক্রলিং স্পিড নিয়ন্ত্রণ |
