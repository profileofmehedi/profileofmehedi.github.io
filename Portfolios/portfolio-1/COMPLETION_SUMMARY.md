## 🔒 Data Security & Backup

### Storage Location

- **Where**: Browser's localStorage
- **Scope**: Your domain only
- **Size**: 5-10MB capacity
- **Persistence**: Survives page reload

### Backup Strategy

```javascript
// Export your data
const backup = JSON.stringify(portfolioData);
// Save to file or cloud storage

// Import your data
portfolioData = JSON.parse(backup);
saveData(portfolioData);
```

### Important Notes

- ⚠️ Clearing browser cache removes data
- ⚠️ Private/incognito mode may limit access
- ⚠️ Each domain has separate storage
- ✅ Regular backups recommended
