================================================================================
          CODEX: 7+ YEARS SENIOR FULL-STACK .NET & LEAD ENGINEERING PLATFORM
================================================================================

Codex (hosted under profileofmehedi.github.io/Mehedi-Stack) is an enterprise-grade, visually stunning, and highly interactive software engineering knowledge and career cracking portal designed for Bengali-speaking developers aiming for 7+ Years Experience Senior Software Engineer, Technical Lead, and Solution Architect roles.

The platform operates as a high-performance static web application built using HTML5, CSS3, and Bootstrap 5 without requiring heavy frontend JavaScript frameworks or server-side databases. All interactive behaviors—including pure CSS dark mode toggling, collapsible sidebars, multi-stage quizzes, and interactive code sandboxes—are driven using pure CSS selectors and standard HTML5 elements.

1. CORE SPECIALIZATION TRACKS (7+ YEARS LEVEL)
--------------------------------------------------------------------------------

1. dotnet-enterprise.html:
   - Deep CLR Internals: JIT Compilation, Tiered Compilation, Dynamic PGO, Native AOT.
   - Advanced Garbage Collection: Gen 0, Gen 1, Gen 2, LOH Fragmentation & POH, ArrayPool<T>.
   - Zero-Allocation C#: Span<T>, Memory<T>, MemoryMarshal, ref struct.
   - Async Plumbing: IAsyncStateMachine, SynchronizationContext, Task vs ValueTask, ThreadPool Starvation.
   - Enterprise Architecture: Clean Architecture, Domain-Driven Design (DDD), CQRS with MediatR.
   - High-Throughput Data Access: EF Core Split Queries vs Dapper Micro-ORM, Captive Dependencies in DI.

2. database-mastery.html:
   - SQL Server: Clustered vs Non-Clustered B-Trees, Covering Index & INCLUDE, Execution Plans (Seek vs Scan, Lookups, Spills), Parameter Sniffing, Isolation Levels & Deadlocks.
   - PostgreSQL: MVCC Internals, Tuple Bloat, VACUUM tuning, EXPLAIN (ANALYZE, BUFFERS), GIN Indexes on JSONB, PgBouncer Connection Pooling modes.
   - Oracle Database & PL/SQL: SGA/PGA Architecture, Compound Triggers, Autonomous Transactions, BULK COLLECT & FORALL with SAVE EXCEPTIONS (eliminating context switching).
   - Redis & Distributed Caching: Cache Stampede / Thundering Herd, RedLock Distributed Locks, Cache Avalanche & Penetration.

3. frontend-mastery.html:
   - Modern CSS3: CSS Grid vs Flexbox, Container Queries (@container), clamp(), GPU Acceleration & Browser Rendering Pipeline (Reflow vs Repaint vs Composite).
   - jQuery Enterprise Maintenance: High-performance DOM selection, Event Delegation, Detached DOM Memory Leaks, Strangler migration to modern SPA.
   - Angular 18 Enterprise: Standalone Components, Modern Control Flow (@for track), Signals vs RxJS, Flattening operators (switchMap, exhaustMap, concatMap, mergeMap), OnPush Change Detection, Zoneless Angular, @defer Deferrable Views, HTTP Auth Interceptors.

4. system-design.html:
   - 5-Step System Design Interview Framework: Clarification, Capacity Estimation, High-Level Diagram, Component Deep Dive, Fault Tolerance.
   - Distributed Fundamentals: CAP Theorem, PACELC, ACID vs BASE, Idempotency Keys.
   - Messaging: Apache Kafka vs RabbitMQ architectural trade-offs.
   - Distributed Consistency & Transactions: Transactional Outbox Pattern with CDC, Saga Pattern (Orchestration vs Choreography), Polly Circuit Breaker, Token Bucket Rate Limiting.
   - 3 Real-World Case Studies: High-Volume E-Commerce Flash Sale System, Distributed URL Shortener (100M URLs), Real-Time Push Notification Engine.

5. server-devops.html:
   - Windows Server & IIS: WAS, HTTP.sys, Application Pools, Worker Process (w3wp.exe), In-Process vs Out-of-Process hosting, AppPool Recycling traps & Zero Downtime.
   - Linux Server Administration: Essential bash commands (htop, ps, free, ss), systemd daemon service configuration (/etc/systemd/system/), live logs with journalctl.
   - Nginx Reverse Proxy: SSL Termination with Let's Encrypt / Certbot, proxy_pass, rate limiting, gzip/brotli.
   - Docker & Containerization: Production Multi-stage Dockerfiles (reducing image from 850MB to 80MB alpine), Docker Compose orchestration with healthchecks.
   - Production Diagnostics & Crash Analysis: Capturing live memory dumps with dotnet-dump, dumpheap -stat, gcroot, dotnet-trace flame graphs for 100% CPU crisis.

6. senior-interview-vault.html & interview-vault.html:
   - Senior vs Mid-Level vs Junior Answering Mindset: Explaining trade-offs, internal mechanics, and production metrics.
   - Top 155 Deep Scenario-Based Questions & Answers across Junior (0-2 Yrs), Mid-Level (2-5 Yrs), and Senior / Lead (5-7+ Yrs).
   - Covering: C# & .NET 8/9, SQL Server, PostgreSQL, Oracle PL/SQL, Redis, CSS3, jQuery, Angular 18, System Design, Microservices, Windows IIS, Linux systemd, Nginx, Docker, and STAR Leadership.
   - Zero-dependency client-side instant search, level filter pills, topic filter pills, expand/collapse self-test mode.
   - Full Mobile Responsiveness: Mobile Bottom Navigation Bar (app-like UX) and Floating Back-to-Top button across all key pages.
