================================================================================
                      CODEX: BENGALI PROGRAMMING LEARNING PLATFORM
================================================================================

Codex is a premium, visually stunning, and highly interactive programming education platform designed specifically for Bengali-speaking learners. The platform mimics a modern SaaS product (inspired by Stripe, Apple, Linear, and Duolingo) while operating entirely as a high-performance static web application built using HTML5, CSS3, and Bootstrap 5.

There is NO backend database or heavy JavaScript framework (like React or Vue) in use. All interactive behaviors—including dark mode toggling, the collapsible sidebar layout, dynamic page quizzes, and the animated concept diagrams—are driven using advanced pure CSS selectors and standard HTML5 elements.

--------------------------------------------------------------------------------
1. KEY FEATURES & DESIGN SYSTEM
--------------------------------------------------------------------------------

* PREMIUM DARK & LIGHT MODE SANS-JS:
  Uses a hidden checkbox input hack (#theme-toggle) to override custom CSS variables (:root properties) smoothly across the entire site.

* RESPONSIVE COLLAPSIBLE SIDEBAR:
  Features an elegant, space-saving sidebar with smooth ease transitions. It is toggled via a pure CSS checkbox hack (#sidebar-collapse-toggle) and adapts automatically to mobile, tablet, and desktop views.

* 24 UNIQUE ANIMATED CONCEPT DIAGRAMS (REAL-LIFE ANALOGIES):
  To make abstract programming concepts intuitive, every single lesson features its own unique, CSS-animated diagram paired with a real-life analogy:
  - 1-1 (JIT Pipeline): Recipe book (C#) -> Chef (JIT) -> Served Plate (Machine Code).
  - 2-1 (Stack vs Heap): Small office desk drawer (Stack) with chabi pointing to a large warehouse locker (Heap).
  - 2-2 (Type Casting): Pouring water from a 2-liter jug (double) into a 250ml cup (int), illustrating data truncation.
  - 2-3 (Null-Coalescing ??): Backup spare tire instantly sliding out of the trunk when the primary tire fails (null).
  - 3-1 (If-Else): Railway track connection switch toggled by True/False conditions.
  - 3-2 (Looping): Ferris wheel (merry-go-round) turning 5 rounds before letting passenger exit.
  - 4-1 (Class vs Object): Toy mold (Class) pressing out plastic toy cars (Objects).
  - 5-1 (Arrays): Six-slot egg carton representing contiguous memory allocation.
  - 6-3 (Exception Catching): Circus acrobat falling safely into a try-catch net instead of crashing.
  - 7-2 (IDisposable): Faucet valve that shuts off the water flow to prevent leaks.
  - 7-3 (Span<T>): Magnifying glass sliding over a book page to read a slice without copy overhead.
  - 8-1 (Async/Await): Food order buzzer system that lets customers sit down and read while waiting.
  - 8-2 (Reflection): Airport X-ray scanner displaying suitcase contents without opening it.

* 24 INTERACTIVE SELF-ASSESSMENT QUIZZES:
  Each lesson features a CSS-only interactive quiz at the bottom. By checking the submit label linked to a toggle selector, it instantly evaluates the radio inputs:
  - Correct answers are highlighted in glowing emerald green with a checkmark icon.
  - Incorrect answers turn red with a crossmark icon.
  - A hidden Bengali solution breakdown (feedback-msg) fades up dynamically to explain the concept.
