এনভায়রনমেন্ট ও CLI কমান্ডস

সি# প্রোগ্রামিং শুরু করার জন্য আমাদের পিসিতে প্রয়োজনীয় সফটওয়্যার ইনস্টল এবং রান করতে হবে। সি# রান করতে আমাদের ২টি মূল জিনিস প্রয়োজন:
১. **ডটনেট SDK (Software Development Kit):** এটি কম্পাইলার ও লাইব্রেরি সরবরাহ করে।
২. **কোড এডিটর:** যেমন VS Code বা Visual Studio।

ডটনেট SDK ইনস্টল করার নিয়ম

- ডটনেটের অফিসিয়াল ওয়েবসাইট (dotnet.microsoft.com) এ গিয়ে সর্বশেষ **.NET SDK** সংস্করণ ডাউনলোড করে ইনস্টল করুন।
- ইনস্টলেশন সফল হয়েছে কিনা তা যাচাই করতে আপনার পিসির CMD বা টার্মিনালে dotnet --version লিখে এন্টার চাপুন। এটি আপনার পিসিতে থাকা ডটনেটের ইনস্টলড সংস্করণ দেখাবে।

ডটনেট CLI (Command Line Interface) ব্যবহার

ডটনেট CLI আমাদের প্রজেক্ট পরিচালনা করার সহজ কমান্ড প্রোভাইড করে। নিচে কিছু গুরুত্বপূর্ণ কমান্ড দেওয়া হলো:

টার্মিনাল কমান্ড প্রম্পট
$ dotnet new console -o MyFirstApp
# MyFirstApp নামে একটি নতুন কনসোল প্রজেক্ট ফোল্ডার তৈরি করবে।

$ dotnet build
# কোডে কোনো ভুল বা বাগ আছে কিনা তা বিল্ড করে কম্পাইল করবে।

$ dotnet run
# প্রজেক্টটি বিল্ড করে সাথে সাথে টার্মিনালে কোড রান করবে।
