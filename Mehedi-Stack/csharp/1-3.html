প্রথম কোডের অ্যানাটমি

একটি ফাইল তৈরি করার পর প্রথম সি# কোডটি কেমন দেখায় এবং সেটির প্রতি লাইনের আসল কাজ কী, তা জানা অত্যন্ত গুরুত্বপূর্ণ ধাপ। 

using System;

namespace HelloCodex
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("হ্যালো বাংলাদেশ!");
        }
    }
}

প্রতিটি কীওয়ার্ড ও লাইনের সহজ ব্যাখ্যা

- using System; এটি আমাদের System নামক নেমস্পেস থেকে প্রয়োজনীয় বিল্ট-ইন ক্লাসসমূহ (যেমন Console) সরাসরি ব্যবহার করতে সাহায্য করে। এই লাইন না লিখলে আমাদের প্রতিবার System.Console.WriteLine() টাইপ করতে হতো।
- namespace HelloCodex: এটি হলো কোডগুলোকে সুবিন্যস্তভাবে সাজানোর ফোল্ডার মেকানিজম।
- class Program: সি# এ সব কোড কোনো না কোনো ক্লাসের ভেতরেই থাকতে হবে। ক্লাস হলো অবজেক্টের ব্লু-প্রিন্ট।
- static void Main(string[] args): এটি সি# কনসোল অ্যাপ্লিকেশনের প্রবেশদ্বার (Entry Point)।

১.৩: বাস্তব উদাহরণ - বিনোদন পার্কের প্রধান ফটক (Main Gate)
পার্কের গেট বন্ধ
Main() এন্ট্রি পয়েন্ট ওপেন
একটি পার্কে ঢোকার যেমন একটিমাত্র মেইন গেট থাকে, সি# অ্যাপ্লিকেশনের সব কোড এক্সিকিউশনও Main() মেথড থেকেই শুরু হয়।

কুইজ: নিজের জ্ঞান যাচাই করুন

সি# কনসোল অ্যাপ্লিকেশনের রানটাইম এন্ট্রি পয়েন্ট বা প্রবেশদ্বার কোনটি?

ফলাফল:

সহীহ উত্তর static void Main(string[] args)! সি# কনসোল অ্যাপ্লিকেশনের সব কোড এক্সিকিউশন মেইন মেথড থেকে শুরু হয়।
