Advanced Concept

Short-Circuiting

যদি কোনো Middleware পরের Middleware-এ না যায় তাহলে বলা হয় Short-Circuit। Auth fail হলে Controller-এ না গিয়ে সরাসরি 401 ফেরত পাঠায়।

Auth Success
Logging → next() ✅
Auth → Token Valid → next() ✅
Endpoint → Response তৈরি ✅
← Response উল্টো পথে ফিরে
Auth Fail (Short-circuit)
Logging → next() ✅
Auth → Token Invalid ❌
401 Unauthorized — বন্ধ!
Controller কখনো দেখেনি

// ❌ ভুল — Authorization আগে, Authentication পরে!
var app = builder.Build();

app.UseAuthorization();      // ❌ User কে এখনো চিনিনি!
app.UseRouting();
app.UseAuthentication();   // ❌ দেরিতে এলো
app.MapControllers();
// ✅ সঠিক — নির্ধারিত ক্রমে
var app = builder.Build();

app.UseExceptionHandler(); // সবার আগে Exception ধরো
app.UseStaticFiles();      // Static file — Routing আগে
app.UseRouting();           // URL ম্যাচ করো
app.UseAuthentication();    // User চিনো
app.UseAuthorization();     // Permission চেক করো
app.MapControllers();       // Controller-এ যাও
Custom Middleware তৈরি
public class RequestTimingMiddleware {
    private readonly RequestDelegate _next;

    public RequestTimingMiddleware(RequestDelegate next)
        => _next = next;

    public async Task InvokeAsync(HttpContext context) {
        var sw = Stopwatch.StartNew(); // Request শুরু

        await _next(context); // পরের Middleware-এ যাও

        sw.Stop();                     // Response ফিরলে
        // Response-এ Header যোগ করো
        context.Response.Headers["X-Response-Time"]
            = sw.ElapsedMilliseconds + "ms";
    }
}

// Program.cs-এ যোগ করুন
app.UseMiddleware<RequestTimingMiddleware>();
API Differences

Use vs Run vs Map

app.Use()
Pipeline-এ Middleware যোগ করে। next() কল করে পরের Middleware-এ যায়।
app.Use(async (ctx, next) => { // Request await next(); // Response });
app.Run()
Terminal Middleware। পরের কাউকে কল করে না। Pipeline এখানেই শেষ।
app.Run(async ctx => { await ctx.Response .WriteAsync("Done!"); // পরের কেউ নেই });
app.Map()
URL Path অনুযায়ী আলাদা Branch তৈরি করে। Sub-Pipeline।
app.Map("/api", apiApp => { apiApp.UseAuthentication(); apiApp.MapControllers(); });
IMiddleware — DI-Friendly
Convention-Based
IMiddleware (DI)
// Convention-based — DI inject করা কঠিন
public class MyMiddleware {
    private readonly RequestDelegate _next;
    private readonly ILogger _logger;

    public MyMiddleware(RequestDelegate next, ILogger<MyMiddleware> logger)
    { _next = next; _logger = logger; }

    public async Task InvokeAsync(HttpContext ctx)
    { await _next(ctx); }
}
// ✅ IMiddleware — Scoped DI সহজ
public class MyMiddleware : IMiddleware {
    private readonly IMyService _service;

    public MyMiddleware(IMyService service)
        => _service = service;   // Scoped service OK!

    public async Task InvokeAsync(
        HttpContext ctx, RequestDelegate next) {
        await _service.DoWorkAsync();
        await next(ctx);
    }
}
services.AddScoped<MyMiddleware>();  // DI-তে Register
Global Exception Handling
// সবার প্রথমে Exception Middleware রাখুন
public class GlobalExceptionMiddleware : IMiddleware {
    private readonly ILogger<GlobalExceptionMiddleware> _log;

    public async Task InvokeAsync(HttpContext ctx, RequestDelegate next) {
        try {
            await next(ctx);
        }
        catch (NotFoundException ex) {
            ctx.Response.StatusCode = StatusCodes.Status404NotFound;
            await ctx.Response.WriteAsJsonAsync(new { error = ex.Message });
        }
        catch (Exception ex) {
            _log.LogError(ex, "Unhandled Exception");
            ctx.Response.StatusCode = StatusCodes.Status500InternalServerError;
        }
    }
}

Response Compression Middleware
// ✅ Response Compression যোগ করুন
// Program.cs
builder.Services.AddResponseCompression(options => {
    options.EnableForHttps = true;
    options.Providers.Add<BrotliCompressionProvider>();
    options.Providers.Add<GzipCompressionProvider>();
});

var app = builder.Build();

// Routing-এর আগে রাখুন
app.UseResponseCompression();
app.UseRouting();
app.UseAuthentication();
app.UseAuthorization();
app.MapControllers();

app.Run();
// ফলাফল: Response size ৭০-৮০% কমে আসে!
