Dependency Injection ব্যবহার করুন
new Service() না — Constructor Injection দিয়ে Service পান
Bad vs Good
❌ Bad✅ Good 
// ❌ Tight Coupling — Test করা কঠিন
public class OrderController {
    private readonly OrderService _svc = new OrderService();
    // DbContext, EmailService সব hard-coded!
}
// ✅ Constructor Injection — Loose Coupling
public class OrderController(IOrderService svc) {
    _svc = svc; // DI Container inject করবে
}
// Program.cs: services.AddScoped<IOrderService, OrderService>();

Async/Await সঠিকভাবে ব্যবহার করুন
.Result বা .Wait() কখনো ব্যবহার করবেন না — Thread Block হয়
Blocking Mode
Thread #1 — Request
Thread #2 — Request
Thread Pool — BLOCKED ⛔
Async Mode
Thread #1 — await DB
Thread #2 — Free ✓
Thread #3 — New Request ✓

Controller-এ try-catch নয় — Global handler দিয়ে consistent error response
