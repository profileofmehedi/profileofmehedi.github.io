# Coding Drop — Interactive Video Presentation Portal

এটি **Coding Drop** ইউটিউব চ্যানেলের জন্য ডিজাইন করা একটি ইন্টারেক্টিভ প্রেজেন্টেশন হাব। এটি মূলত ভিডিও রেকর্ড করার সময় সহজে স্লাইড কন্ট্রোল এবং প্রিমিয়াম ভিজ্যুয়াল ডেমো প্রদর্শন করার জন্য তৈরি করা হয়েছে।

---

## 📂 প্রোজেক্ট স্ট্রাকচার (File Breakdown)

```text
Coding Drop/
├── index.html                   # মূল ল্যান্ডিং পোর্টাল (স্লাইড নেভিগেশন হাব)
├── README.md                    # প্রোজেক্টের নির্দেশিকা ও বিবরণী
└── Presentations/               # প্রতিটি টপিকের প্রেজেন্টেশন স্লাইড
    ├── Dependency Injection/
    │   ├── main.html            # DI অডিয়েন্স স্লাইড (লাইফটাইম ভিজ্যুয়ালাইজার সহ)
    │   └── scripts.html         # DI প্রেজেন্টার স্ক্রিপ্ট ও কন্ট্রোলার
    ├── JWT/
    │   ├── main.html            # JWT অডিয়েন্স স্লাইড (টোকেন ডিকোডার সহ)
    │   └── scripts.html         # JWT প্রেজেন্টার স্ক্রিপ্ট ও কন্ট্রোলার
    └── SOLID Principles/
        ├── main.html            # SOLID অডিয়েন্স স্লাইড (রিয়েল-ওয়ার্ল্ড মডেল সহ)
        └── scripts.html         # SOLID প্রেজেন্টার স্ক্রিপ্ট ও কন্ট্রোলার
```

### ১. মূল পোর্টাল (`index.html`)
- একটি প্রিমিয়াম গ্লাস-মর্ফিক ইউজার ইন্টারফেস (UI)।
- এখান থেকে প্রতিটি বিষয়ের **Presenter View** (যা রেকর্ডারের স্ক্রিনে থাকবে) এবং **Audience Window** (যা রেকর্ডিং ভিউপোর্টে থাকবে) সরাসরি ওপেন করা যায়।

### ২. প্রেজেন্টার ভিউ (`scripts.html`)
- **উদ্বেশ্য**: ভিডিও রেকর্ড করার সময় আপনার স্ক্রিনে থাকবে।
- **কি রয়েছে**: 
  - প্রতিটি স্লাইডের জন্য বিস্তারিত **বাংলা ন্যারেটিভ বা স্ক্রিপ্ট** (যা রেকর্ড করার সময় পড়তে হবে)।
  - স্লাইড পরিবর্তন করার জন্য নেভিগেশন বাটন ও কীবোর্ড কন্ডিশন (`ArrowRight` / `ArrowLeft`)।
  - প্রেজেন্টেশন ডুরেশন ট্র্যাকিংয়ের জন্য একটি ডাইনামিক স্টপওয়াচ টাইমার।
  - অডিয়েন্স উইন্ডো কানেক্টেড আছে কিনা তা জানার জন্য কানেকশন ইন্ডিকেটর।

### ৩. অডিয়েন্স উইন্ডো (`main.html`)
- **উদ্বেশ্য**: এটি রেকর্ডিং স্ক্রিনে বা OBS স্টুডিওর উইন্ডো ক্যাপচারে থাকবে।
- **কি রয়েছে**:
  - সম্পূর্ণ ফুলস্ক্রিন সিনেম্যাটিক স্লাইড ভিউ (কোনো ডিস্টার্বিং সাইডবার বা উইন্ডো কন্ট্রোল নেই, ইনডেক্স সাইডবার স্থায়ী)।
  - প্রিমিয়াম ফন্ট কম্বিনেশন: **Hind Siliguri** (বাংলার জন্য) এবং **Plus Jakarta Sans** (ইংরেজির জন্য)।
  - **ইন্টারেক্টিভ কোড প্যানেল**: C# কোডের Bad vs Good প্র্যাকটিসের তুলনামূলক সুইচার।
  - **ভিজ্যুয়াল মডেল**: বাস্তব জীবনের অ্যানালজি ও অ্যানিমেশন (যেমন: সুইস আর্মি নাইফ, দেয়াল সকেট, খেলনা হাঁসের এক্সেপশন ক্র্যাশ অ্যালার্ট, ল্যাম্পের আলো ছড়ানো ইত্যাদি)।

## ⚡ সিনক্রোনাইজেশন মেকানিজম (Sync System)

এই পোর্টালের প্রেজেন্টার ভিউ এবং অডিয়েন্স উইন্ডো সম্পূর্ণ সিঙ্কড অবস্থায় চলে। এর জন্য জাভাস্ক্রিপ্টের **`BroadcastChannel` API** ব্যবহার করা হয়েছে:

1. **চ্যানেল নেমিং**:
   - SOLID: `solid_presentation`
   - DI: `di_presentation`
   - JWT: `jwt_presentation`

2. **যোগাযোগ পদ্ধতি**:
   - যখন আপনি প্রেজেন্টার স্ক্রিনে (`scripts.html`) পরের স্লাইডে যান, এটি ব্রডকাস্ট চ্যানেলে একটি বার্তা পাঠায়: 
     ```javascript
     BC.postMessage({ type: 'nav', idx: cur });
     ```
   - অডিয়েন্স উইন্ডো (`main.html`) এই বার্তাটি রিসিভ করে এবং মুহূর্তের মধ্যে একই স্লাইডে আপডেট হয়ে যায়:
     ```javascript
     BC.onmessage = (e) => { if(e.data.type === 'nav') { cur = e.data.idx; renderSlide(); } };
     ```
   - এছাড়াও কানেকশন সচল রাখার জন্য প্রেজেন্টার থেকে প্রতি ৩ সেকেন্ড পর পর একটি `ping_from_presenter` সংকেত পাঠানো হয়, যা অডিয়েন্স উইন্ডো থেকে `ping` ফিডব্যাক দিয়ে কানেকশন লাইভ রাখে।

## 🚀 কীভাবে চালু করবেন (How to Run)

১. যেকোনো লোকাল সার্ভার ব্যবহার করে প্রোজেক্টের রুট ডিরেক্টরি রান করুন (যেমন: VS Code-এর **Live Server** এক্সটেনশন বা পাইথনের `python -m http.server`)।
২. ব্রাউজারে `index.html` পেজটি ওপেন করুন।
৩. আপনার পছন্দের টপিকের **Audience Window**-টি ক্লিক করে আলাদা উইন্ডো হিসেবে ওপেন করে রেকর্ডিং স্ক্রিনে/প্রজেক্টরে নিয়ে যান।
৪. এরপর **Presenter View**-টি আপনার প্রধান মনিটরে ওপেন করে কন্ট্রোল শুরু করুন।
৫. প্রেজেন্টার উইন্ডোতে বাটন বা কীবোর্ডের অ্যারো কি দিয়ে নেভিগেট করলে অডিয়েন্স স্ক্রিন স্বয়ংক্রিয়ভাবে সিঙ্ক হয়ে যাবে!
