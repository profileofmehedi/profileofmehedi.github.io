1. CLR Internals & Memory Management

The Execution Lifecycle

Understanding MSIL (Common Intermediate Language) and JIT (Just-In-Time) compilation. .NET Core now supports Tiered Compilation, which optimizes hot paths during runtime.

Advanced Memory Architecture
  • Garbage Collection (GC): Generations 0, 1, 2. The Large Object Heap (LOH) is for objects > 85KB. The new Pinned Object Heap (POH) in .NET 5+ reduces fragmentation for pinned buffers.
  • Compaction vs. Sweeping: Gen 0 and 1 are always compacted; Gen 2 is traditionally swept (though it can be compacted).
  • Stack vs. Heap: Value types on stack (fixed size, scope-based), Reference types on heap (managed by GC).
// Senior Question: How to avoid LOH fragmentation?
// Answer: Use ArrayPool<T> to reuse large buffers instead of frequent allocations.
var pool = ArrayPool<byte>.Shared;
var buffer = pool.Rent(100_000); // Rented from LOH if necessary
try { /* Use buffer */ } finally { pool.Return(buffer); }

2. Advanced C# (10 - 13.0)

Performance-Oriented Types
  • Span<T> & Memory<T>: Type-safe views into contiguous memory. Crucial for zero-allocation parsing and string manipulation.
  • ref struct: Guaranteed stack-only types that cannot be boxed or captured by async lambdas.
Modern Language Syntax
  • Records: Immutable data types with built-in value-based equality.
  • Pattern Matching: Recursive patterns, property patterns, and relational patterns in switch expressions.
  • Interpolated Strings: Optimized in C# 10+ using handlers to avoid allocations.
// Pattern Matching with Property access
public string GetRoleInfo(Employee e) => e switch {
    { Role: "Lead", Seniority: > 5 } => "Principal Engineer",
    { Role: "Lead" } => "Senior Lead",
    _ => "Engineer"
};

3. Asynchronous Programming & TPL

The Async State Machine

The compiler transforms async methods into a state machine. Every await is a potential suspension point where the thread is released back to the pool.

Advanced Patterns
  • ValueTask<T>: Use when a method might complete synchronously to avoid heap-allocating a Task object.
  • ConfigureAwait(false): Crucial for library code to avoid capturing the SynchronizationContext, preventing potential deadlocks.
  • Task.Run vs Task.Yield: Offloading work to the thread pool vs. yielding the current thread to the scheduler.
// Advanced: Handling multiple tasks efficiently
public async Task ProcessInParallel(IEnumerable<string> urls) {
    var tasks = urls.Select(url => DownloadAsync(url));
    await Task.WhenAll(tasks); // Optimized for multiple waits
}

4. ASP.NET Core Architecture

The Request Pipeline

The pipeline consists of Middleware. Each component can process the request, pass it to next(), or short-circuit the pipeline.

Dependency Injection (DI) Internals
  • Lifetimes: Transient (new each time), Scoped (once per request), Singleton (once per app).
  • Captive Dependency: A serious bug where a Singleton service depends on a Scoped service, effectively keeping the Scoped service alive forever.
Filters vs. Middleware

Filters run after the Routing middleware and have access to the MVC context (ActionContext). Middleware is lower-level and operates on the raw HttpContext.

5. Entity Framework Core (EF Core)

Performance Tuning
  • AsNoTracking(): Disables change tracking for read-only queries, significantly reducing memory and CPU usage.
  • Eager vs. Explicit vs. Lazy Loading: Seniors must explain the N+1 problem and how to avoid it using .Include().
  • Compiled Queries: Pre-compiling LINQ queries for high-frequency execution.
Advanced Features
  • Global Query Filters: Perfect for Soft-Delete or Multi-tenancy (e.g., HasQueryFilter(e => !e.IsDeleted)).
  • Interceptors: Intercepting DB operations for logging, auditing, or performance monitoring.

6. Unit & Integration Testing

The Testing Pyramid

Senior engineers prioritize Unit tests for logic, Integration tests for DB/External APIs, and End-to-End tests for critical paths.

Modern Tooling
  • xUnit / NUnit: Standard frameworks.
  • Moq / NSubstitute: Mocking abstractions.
  • WebApplicationFactory: The professional way to run integration tests for ASP.NET Core in-memory.
  • TestContainers: Running real databases (SQL Server, Redis) in Docker for integration tests.

7. Microservices & Distributed .NET

Communication Styles
  • gRPC: Contract-first, high-performance binary communication over HTTP/2.
  • MassTransit / NServiceBus: Service bus abstractions for event-driven architecture (RabbitMQ, Azure Service Bus).
  • SignalR: Real-time, bi-directional communication.
Resiliency

Using Polly for Retry, Circuit Breaker, and Bulkhead patterns in microservices communication.
