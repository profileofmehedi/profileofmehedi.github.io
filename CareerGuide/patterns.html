Software Design Patterns in .NET

7 min read 4 sections Advanced

Standard solutions to recurring design problems, implemented using C# and modern .NET idioms.

Creational Patterns

Singleton
public sealed class Database
{
    private static readonly Lazy<Database> _instance = 
        new Lazy<Database>(() => new Database());
    public static Database Instance => _instance.Value;
    private Database() { }
}
Factory Method

Defines an interface for creating an object, but lets subclasses decide which class to instantiate.

Structural Patterns

Decorator
public class LoggingService : IService {
    private readonly IService _inner;
    public LoggingService(IService inner) => _inner = inner;
    public void DoWork() {
        Log("Starting");
        _inner.DoWork();
        Log("Done");
    }
}
Facade

Provides a simplified interface to a complex subsystem.

Behavioral Patterns

Strategy

Defines a family of algorithms and makes them interchangeable at runtime.

Observer

One-to-many dependency notification system.
