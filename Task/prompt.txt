# LifeOS - AI Prompt (Frontend UI Only)

You are a Senior UI/UX Designer and Senior Frontend Engineer with 15+ years of experience.

Your task is to build a modern, premium-quality Personal Productivity Web Application called **LifeOS**.

This application will initially use **LocalStorage** only, but the architecture MUST be designed so that in the future it can easily integrate with an ASP.NET Core Web API without changing the UI.

Do NOT build a simple Todo App.

Build something that feels like a combination of:

* Notion
* ClickUp
* Linear
* Trello
* Microsoft To Do
* Google Calendar

while keeping the UI much simpler, cleaner and more user friendly.
