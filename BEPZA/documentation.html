1. How to Use Executive Dashboard

What is the Executive Dashboard?

The Executive Dashboard is your main control center where you can see all important BEPZA information at a glance. This page shows key numbers, trends, and alerts that need your attention as Chairman.

1
Logging into the System
How to Login:
  1. Open your web browser (Chrome, Firefox, Safari, or Edge)
  2. Go to the BEPZA portal website
  3. Enter your login credentials:
    • Email: admin@bepza.gov.bd
    • Password: admin123
  4. Click the "Login" button
  5. You will automatically be redirected to the Executive Dashboard
2
Understanding the Dashboard Layout
Top Section - Key Metrics
  • Total EPZs: Shows number of operational zones (currently 8)
  • Active Companies: Number of registered companies (1,245)
  • Total Employment: Total workers across all EPZs (485,000)
  • Export Value: Annual export value ($12.8 billion)
Charts Section
  • Export Trends: Line chart showing monthly performance
  • EPZ Performance: Bar chart comparing different zones
  • Investment Distribution: Pie chart showing sector-wise investment
  • Employment Growth: Area chart showing workforce trends
3
Using Quick Action Buttons
Available Actions
Downloads current data as Excel file
Opens calendar to schedule board meetings
Shows items requiring your approval
View urgent notifications and alerts
4
Reading the Performance Indicators
Green Status

Everything is performing well and on target. No action needed.

Yellow Status

Attention needed. Performance is below optimal but manageable.

Red Status

Immediate action required. Critical issue needs chairman intervention.

5
Navigating to Other Reports
Using the Sidebar Menu:
  1. Look at the left side of your screen - you'll see a menu with different options
  2. Each menu item represents a different report or analysis
  3. Click on any menu item to go to that specific report
  4. The active page will be highlighted in blue
  5. You can always return to the main dashboard by clicking "Executive Dashboard"
Pro Tips for Using the Dashboard
  • Check daily: Visit the dashboard every morning to see overnight updates
  • Monitor alerts: Red badges on metrics require immediate attention
  • Use mobile: The dashboard works on tablets and phones when you're traveling
  • Export data: Download reports before important meetings
  • Hover for details: Move your mouse over charts to see detailed numbers
Important Security Notes
  • Always logout when finished, especially on shared computers
  • Never share your login credentials with anyone
  • If you see suspicious activity, contact IT immediately
  • The system will automatically log you out after 30 minutes of inactivity
