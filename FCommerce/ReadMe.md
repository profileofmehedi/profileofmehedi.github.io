# FCommerce SaaS - Professional Social Commerce Demo

A production-quality, high-fidelity frontend demo system for a Social Commerce SaaS platform. Built as a high-performance **Single Page Application (SPA)** using only Vanilla HTML5, CSS3, Bootstrap 5, and jQuery.

## 🚀 Key Features

- **SPA Architecture**: Smooth, flicker-free navigation using a custom-built hash-based router.
- **⌨️ Command Center (Ctrl+K)**: Mac-style global search and action bar. Jump to pages, toggle dark mode, or search products instantly via keyboard.
- **📡 Live Activity Feed**: Real-time audit trail sidebar that tracks user navigation, system events, and data changes.
- **📖 Contextual Help System**: A "Page Help" system that provides specific instructions and pro-tips for every module via a beautiful floating pulse button.
- **Intelligent AI Assistant**: A data-aware AI chat that queries live LocalStorage state to provide insights on inventory, sales, and customers.
- **Rich Data Persistence**: Fully simulated backend using `LocalStorage` with pre-seeded rich demo data.
- **Live Business Simulation**: Real-time toast notifications and activity logs for a "living" application feel.
- **Dark Mode Support**: System-wide theme switching with persistent user preference.
- **Premium UX**: Professional skeleton loaders, Animate.css transitions, and high-quality Chart.js visualizations.

## 📁 Project Structure

- `index.html`: Modern, secure-style Login page with frosted-glass UI.
- `app.html`: The **Main Application Shell**. Manages the Sidebar, Topbar, Activity Feed, and SPA view injection.
- `/assets/css/style.css`: Core design system, Dark Mode variables, and custom SaaS component styles.
- `/assets/js/app.js`: The "Brain" - Handles Routing, Command Center, Activity Logs, and SPA View Registry.
- `/assets/js/storage.js`: The "Database" - Manages LocalStorage, Seeding, and CRUD operations.
- `/assets/js/ui.js`: Global UI interactions, Theme management, and Notifications.

## 📊 Demo Modules

1. **Dashboard**: Real-time KPI cards, sales charts, and automated business insights.
2. **Orders**: Full lifecycle management with CSV export functionality.
3. **Chat**: Interactive inbox with message history and simulated real-time replies.
4. **Customers**: Detailed directory with spending metrics and geographic data.
5. **Inventory**: Visual product grid with "Low Stock" logic and danger indicators.
6. **Ads Manager**: Multi-platform performance tracking (Facebook, Google, Instagram).
7. **AI Assistant**: Conversational UI for data-driven business queries.
8. **Reports**: Deep-dive analytics with doughnut and bar charts.
