Developer API Documentation

Authentication

All API requests require a Bearer Token in the header.

Authorization: Bearer YOUR_API_KEY_HERE
POST /api/v1/orders/create

Create a new shipment request.

Request Body (JSON)
{
  "merchant_id": "M-1001",
  "recipient_name": "Karim Uddin",
  "recipient_phone": "01711...",
  "address": "House 10, Road 5, Dhaka",
  "amount_to_collect": 1200,
  "weight": 0.5
}
Response
{
  "status": "success",
  "tracking_id": "CN-1009",
  "estimated_delivery": "2026-01-23"
}
GET /api/v1/orders/status/{tracking_id}

Get the current status of a parcel.

// GET /api/v1/orders/status/CN-1009

{
  "tracking_id": "CN-1009",
  "current_status": "In Transit",
  "location": "Dhaka Hub"
}
Sandbox Environment

Use the sandbox URL for testing. No real riders will be assigned.

Webhooks

Configure webhooks to receive real-time updates when parcel status changes.
