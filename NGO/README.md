# NGO - Rent / Mess Management System (SaaS Demo)

A complete frontend-only SaaS solution for managing houses, messes, and tenants. Built with HTML, CSS (Bootstrap 5), and JavaScript (jQuery).

## Features
- **Role-Based Access**: Super Admin, Client Admin (Owner), Manager, Tenant.
- **SaaS Management**: Manage clients and plans.
- **Property Management**: Manage houses, floors, and units/rooms.
- **Tenant Management**: Move-in, move-out, and history.
- **Billing System**: Monthly rent generation, utility tracking, and collection.
- **Reports**: Payment history and dues.
- **Local Persistence**: All data is saved in Browser LocalStorage.

## How to Run
1. Open `index.html` in your browser.
2. You will be redirected to the **Login Page**.
