Data & Backups

How Data is Stored

All your changes are saved to your browser's LocalStorage. This means changes are instant and don't require internet.

Backing Up Your Data
  1. Go to:
    Settings page (last item in sidebar)
  2. Click:
    "Export Data" button
  3. Save:
    JSON file will download automatically
  4. Store:
    Keep backup file in a safe location
Restoring from Backup
  1. Go to:
    Settings page
  2. Click:
    "Import Data" button
  3. Select:
    Your backup JSON file
  4. Confirm:
    Data will be restored immediately
Important

Browser data is local to your computer. If you clear browser cache or switch browsers, your changes will be lost. Always keep backups!

Tips & Best Practices

✅ Real-time Preview

As you type in form fields, the preview updates automatically. Use this to perfect your content before saving.

✅ Keyboard Shortcuts

Use Tab to move between fields quickly. Most forms save with a single button click.

✅ Regular Backups

Export your data weekly to ensure you never lose important changes. Store backups in multiple locations.

✅ Track Changes

The dashboard shows your recent changes. Use this to verify updates were saved correctly.

⚠️ Don't Lose Your Session

Don't clear browser cache while logged in. Always logout properly using the logout button.

Frequently Asked Questions

How do I change the password?

In this beta version, the password is fixed as "123456". For production, you'll need to implement proper authentication or contact your developer to change it.

Can I add new sections to the website?

Not from the admin panel currently. New sections require editing the index.html file directly or working with a developer to extend the admin functionality.

How do I upload images?

Images can be uploaded to the appropriate folders (assets/img/) via FTP or file manager. Then reference them in the admin panel using the file path.

What happens if I clear my browser cache?

All your data will be lost. Always export your data to a backup file before clearing cache. You can then import it back after clearing.

Can multiple people access the admin panel?

Currently, there's only one login account. To add multiple users, a backend system would need to be implemented.

Where are my changes reflected?

Changes are saved to LocalStorage, which means they're stored locally in your browser. To reflect changes on the live website, you'd need a backend system or manual HTML updates.
