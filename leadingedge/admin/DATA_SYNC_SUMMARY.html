⚠️ Important Notes

LocalStorage Limitations: Data is stored in your browser only. Clearing cache = losing data. Use Export feature to backup!
Browser Specific: Changes in Chrome won't appear in Firefox unless both access the same server.
Pro Tip: Always export your data weekly using Settings → "Export Data" button. This creates a backup JSON file.
  • Hard Refresh Needed: Sometimes press Ctrl+F5 to see changes (clear cache)
  • Console Check: Press F12 → Console to verify data loading
  • Backup Before Major Changes: Export first, then make edits
  • Same Browser Rule: Use the same browser where you made admin edits

Troubleshooting

🔧 Data Not Appearing?

Solution: Hard refresh (Ctrl+Shift+Delete) and check browser console (F12) for errors.

🔧 Lost All Data?

Solution: Go to Settings → "Import Data" and select your exported JSON backup file.

🔧 load-data.js Not Found?

Solution: Check that file exists at admin/load-data.js and browser Network tab shows 200 status.

🔧 Changes Work in Admin but Not on Website?

Solution: Verify script is loaded (F12 → Network tab). Check for JavaScript errors in console.
