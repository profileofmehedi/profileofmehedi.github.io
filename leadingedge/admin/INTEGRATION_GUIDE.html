# Integration Guide: Admin Panel Data to Website ## Overview The admin panel now automatically syncs all edited content to the main website (index.html). Changes made in the admin panel are instantly reflected on the live website. ## How It Works 1. **Data Storage**: When you edit content in the admin panel, data is saved to browser LocalStorage 2. **Script Loading**: When index.html loads, the `load-data.js` script automatically runs 3. **Content Updates**: The script reads from LocalStorage and updates all website sections ## What Gets Updated The following sections are automatically synced: ### Hero Section - Page title - Subtitle - Primary button text & link - Secondary button text & link - Background video URL ### About Section - About title - Company tagline - Main content text - Feature list (with checkmarks) - "Learn More" button link ### Services Section - All 6 service titles - All 6 service descriptions ### Core Values Section - All 8 value titles - All 8 value descriptions - Icons (pre-assigned) ### Statistics/Clients Section - Countries served - Total clients - Projects completed - Tech partners count ### Contact Section - Headquarters address (street, city, zip) - Branch office address (street, city, zip) - Phone number - Email address - Google Map coordinates (latitude/longitude) ### Meta Tags (SEO) - Website title - Meta description - Meta keywords ## Step-by-Step Usage ### To Edit Website Content: 1. **Login to Admin Panel** - Navigate to: `admin/login.html` - Username: `admin` - Password: `123456` 2. **Select the Section to Edit** - Dashboard (overview of all changes) - Hero (main banner) - About (company information) - Services (6 service offerings) - Core Values (8 company values) - Clients (statistics) - Contact Info (addresses, phone, email) - Settings (SEO meta tags) 3. **Make Your Changes** - Fill in the form fields - Preview changes in real-time - Click "Save" or "Update" button 4. **Visit Main Website** - Open `index.html` in your browser - Changes should appear instantly! - Refresh page if needed (Ctrl+F5 for hard refresh) ## Data Sync Flow ``` Admin Panel (Edit Form) ↓ LocalStorage (JSON storage) ↓ load-data.js (Script on page load) ↓ index.html (Content Updated) ``` ## Important Notes ⚠️ **LocalStorage Limitations:** - Data is stored locally in your browser - Clearing browser cache will delete all data - Each browser/device has its own storage - Data is NOT synced across browsers/devices ✅ **Best Practices:** 1. **Regular Backups**: Export data weekly from Settings → "Export Data" 2. **Use Same Browser**: Always edit from the same browser to keep changes 3. **Clear Browser Properly**: Don't clear cache while logged in 4. **Backup Before Updates**: Export before making major changes ## Testing the Integration ### To verify data is syncing: 1. **Open Admin Panel** - Go to admin/login.html - Login with credentials 2. **Edit a Field** - Go to Hero section - Change the title to something unique - Click Save 3. **Check Main Website** - Navigate to index.html - Scroll to Hero section - Your new title should appear! 4. **Open Browser Console** - Press F12 - Go to Console tab - You should see: "✓ Admin data loader initialized" - And a list of all available data ## Troubleshooting ### Changes Not Appearing? **Solution 1: Hard Refresh** - Press Ctrl+Shift+Delete (or Cmd+Shift+Delete on Mac) - Or press Ctrl+F5 (or Cmd+Shift+R on Mac) **Solution 2: Check Browser Console** - Open DevTools (F12) - Go to Console tab - Look for error messages - Verify data exists: Type `localStorage.getItem('heroData')` **Solution 3: Check LocalStorage** - Open DevTools (F12) - Go to Application tab - Click "LocalStorage" → Select your website - You should see keys like: heroData, aboutData, services, etc. **Solution 4: Check File Path** - Ensure `admin/load-data.js` is accessible - Check browser Network tab (F12 → Network) - Look for load-data.js in the list - If 404, the path is wrong ### Data Lost? **Quick Recovery:** 1. Go to Admin Panel → Settings 2. Scroll down to "Data Management" 3. Click "Import Data" 4. Select your backup JSON file from previous export 5. All data will be restored! ## Future Enhancements The current system uses LocalStorage, which is great for testing.
