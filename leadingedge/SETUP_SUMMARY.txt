┌────────────────────────────────────────────────────────────────────────────────┐
│ ⚠️  IMPORTANT NOTES                                                            │
└────────────────────────────────────────────────────────────────────────────────┘

🔴 KNOW BEFORE YOU USE:

  1. Data is LOCAL to your browser
     → Chrome ≠ Firefox ≠ Safari
     → Use the SAME browser for consistency

  2. Data is LOCAL to your device
     → Computer ≠ Laptop ≠ Phone
     → Use the SAME device

  3. Clearing cache = Losing data
     → Always EXPORT first (Settings → "Export Data")
     → Keep backups safe

  4. LocalStorage size limit: ~5-10 MB
     → Current size: ~50 KB
     → Plenty of room, but export old data periodically

✅ WHAT YOU MUST DO:

  1. Export data weekly
  2. Store backups in multiple locations
  3. Use same browser for edits
  4. Don't clear cache while logged in
