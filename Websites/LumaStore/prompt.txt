Build a premium fashion e-commerce website called **LumaStore**.

## Objective

Create a polished e-commerce frontend demo suitable for:

* Fashion brands
* Boutique stores
* Clothing businesses
* Lifestyle brands

## Pages

* Home
* Shop
* Category
* Product Details
* Cart
* Checkout
* Wishlist
* Account

## Home

Create:

* Premium hero banner
* Featured collection
* New arrivals
* Best sellers
* Promotional banner
* Category showcase
* Testimonials
* Newsletter

## Product Listing

Implement:

* Search
* Category filter
* Price filter
* Size filter
* Color filter
* Sorting
* Pagination

## Product Details

Include:

* Image gallery
* Product name
* Price
* Discount
* Sizes
* Colors
* Quantity
* Add to Cart
* Wishlist
* Product description
* Specifications
* Reviews
* Related products

## Cart

Show:

* Product
* Quantity
* Price
* Subtotal
* Shipping
* Discount
* Total

## Checkout

Create demo checkout:

* Customer information
* Shipping address
* Delivery method
* Payment method placeholder
* Order summary

Do not integrate real payments.

## UX

* Persistent cart
* Wishlist
* Toast notifications
* Loading states
* Empty states
* Mobile bottom navigation if appropriate

## Design

Premium fashion brand:

* Minimal
* Editorial
* Large imagery
* Elegant typography
* Smooth transitions
* Responsive

Use fictional products and prices.

Do not use copyrighted brand assets.
