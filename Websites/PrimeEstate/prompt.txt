Build a premium real estate property website called **PrimeEstate**.

## Objective

Create a modern property discovery platform suitable as a demo for:

* Real estate companies
* Property agents
* Developers
* Rental businesses

## Pages

* Home
* Properties
* Property Details
* Agents
* About
* Blog
* Contact

## Home

Hero search:
“Find a Place You'll Love to Call Home.”

Search controls:

* Buy/Rent
* Location
* Property type
* Price range
* Bedrooms

## Property Listing

Build:

* Grid/list view
* Filters
* Sorting
* Search
* Pagination
* Featured properties

Property card:

* Image
* Price
* Location
* Bedrooms
* Bathrooms
* Area
* Property type
* Favorite button

## Property Details

Include:

* Image gallery
* Property overview
* Features
* Amenities
* Location
* Agent
* Inquiry form
* Similar properties

## Agents

Agent cards:

* Photo
* Name
* Specialization
* Properties
* Contact

## Map

Create a map-ready UI with a professional placeholder if no map API is configured.

## Contact

Inquiry form with validation.

## Design

Premium real-estate aesthetic:

* Large property imagery
* Clean cards
* Elegant typography
* Strong CTA
* Responsive

## UX

* Sticky search
* Mobile filter drawer
* Favorite interaction
* Property comparison-ready architecture

Use realistic fictional property data.
