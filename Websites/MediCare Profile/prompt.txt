Build a premium, production-quality doctor personal website called **MediCare Profile**.

## Objective

Create a professional website for a specialist doctor that NextXenIT can use as a demo for doctors, consultants, and healthcare professionals.

The design should communicate:

* Trust
* Professionalism
* Cleanliness
* Accessibility
* Reliability

Do NOT make it look like a hospital management system. This is a doctor-focused professional website.
