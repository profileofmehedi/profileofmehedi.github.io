Build a premium restaurant website called **UrbanFork**.

## Objective

Create a visually rich restaurant website suitable for a modern premium restaurant/cafe.

Primary goals:

* Showcase food
* Increase reservations
* Increase calls
* Improve brand perception

## Pages

* Home
* Menu
* About
* Gallery
* Reservations
* Offers
* Reviews
* Contact

## Home

Create a strong food-focused hero:

* Restaurant name
* Tagline
* Food imagery placeholders
* View Menu
* Reserve a Table

Add:

* Opening hours
* Location
* Phone
* Featured dishes

## Menu

Build an advanced digital menu:

* Starters
* Main Course
* Seafood
* Desserts
* Beverages

Each item:

* Image
* Name
* Description
* Price
* Vegetarian/spicy/allergen indicators

Add category filtering.
